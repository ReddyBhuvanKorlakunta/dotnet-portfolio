Enterprise Case Management System

Sample data only. No real personal, health or classified data.

1. Design System

WCAG 2.1 AA component library: tokens, tabs, dialog, sortable table, forms. Try it without a mouse.

2. Portal UI

Responsive front-end that fetches the .NET API and falls back to sample data when the API is not running.

3. Enterprise Portal (.NET 8)

Clean Architecture: Domain state machine, Application services, EF Core + SQL Server, JWT + roles, AES-GCM, xUnit tests, Azure DevOps pipeline, Docker. See 02-enterprise-dotnet-portal on GitHub.

Run it: docker compose up --build in that folder, or dotnet test src/EnterprisePortal.Tests.
