# .NET and accessible frontend portfolio
The main runnable project is [Civic Services](02-enterprise-dotnet-portal/README.md), a .NET 10 MVC and C# API case workspace with responsive HTML5, Sass, JavaScript, role-controlled workflows, encryption, browser tests and a separate Windows Web Forms project.

| Requirement | Evidence |
| --- | --- |
| C# / MVC / backend API | Domain, Application, Infrastructure and Web projects |
| Responsive UI / UX | Sign-in, searchable workspace, creation and review screens |
| Sass / HTML5 / JavaScript | frontend/scss and semantic Razor views |
| Enterprise design system | Tokens, component contracts and governance page |
| Bootstrap / Material | Framework adapter source and original component examples |
| WCAG 2.1 AA | axe suite, keyboard checks and manual test protocol |
| SQL Server | Parameterized transactional encrypted snapshot adapter and schema |
| Web Forms | Separate .NET Framework 4.8 project and Windows build job |
| Secure coding | Authentication, authorization, CSRF, encryption and deployment boundaries |

Start with the project README and docs/verification.md. Do not represent automated checks as a formal accessibility certification, formal WCAG training, JAWS experience, agency accreditation, or prior professional experience. The original standalone frontend samples remain for reference; the .NET project is the authoritative end-to-end implementation.
