Design tokens (Sass source of truth)

Change a token in scss/_tokens.scss, recompile, and every component updates. That is the difference from dropping in a component library: the token layer is owned by the enterprise, the components consume it.

Errors are announced with role="alert", linked with aria-describedby, and focus moves to the first invalid field — the pattern JAWS users expect. This form submits nowhere; it is a demo.

Design system vs. component library vs. framework

Framework (Bootstrap): gives you a grid and pre-styled components, fast, but every Bootstrap site looks alike unless you override it.

Component library (Material): gives you ready components with behaviour, but its look, tokens and motion are Google's, not the enterprise's.

Design system: tokens + components + usage rules + accessibility standards, owned by the enterprise. It can use Bootstrap's grid and Material's elevation and still look and behave like one product — which is what this demo does.
